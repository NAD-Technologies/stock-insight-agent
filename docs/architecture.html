Stock Insight Agent: how it works

One page for the code flow, the data flow, what is real and what is not, and where to edit when something needs to change.

REALfetched live from a provider STATIChard-coded assumption in our code MOCKsynthetic, tests only LLMwritten by a language model

1. The short version

The "agent" is a fixed pipeline

A Python function (agent/orchestrator.py) calls the data tools in a set order, with independent ones running at the same time. No model decides which tool to call.

Scores never come from the LLM

Rating, scores, confidence, trade plan and drivers are plain arithmetic in analytics/scoring.py. Same data in, same answer out.

The LLM is used twice per analysis

Once to label news headlines, once to write the summary and bull/bear text. Both are optional and fall back to templates and keywords.

3. What happens when you open a ticker

sequenceDiagram
  participant UI as React UI
  participant API as FastAPI
  participant AG as Orchestrator
  participant Y as Yahoo / extras
  participant M as Analytics
  participant L as LLM (optional)
  UI->>API: GET /api/analyze/STX?profile=balanced
  API->>AG: analyze("STX")
  AG->>Y: 1. get_quote (404 if unknown ticker)
  AG->>Y: 2. history 5y daily + 5m intraday (parallel)
  AG->>M: 3. compute_technicals
  par step 4 to 9, parallel
    AG->>Y: fundamentals
    AG->>Y: analyst view
    AG->>Y: ownership, short, options
    AG->>Y: news (+ Finnhub, Alpha Vantage)
    AG->>Y: SPY, sector ETF, VIX, 10Y yield
    AG->>Y: events (earnings, dividend)
  end
  AG->>L: classify headlines
  L-->>AG: sentiment, impact, catalyst per headline
  AG->>M: 10. score 5 pillars, composite, plan
  AG->>L: 11. write summary, bull, bear, risks
  L-->>AG: narrative (checked against the data)
  AG-->>API: one JSON document
  API-->>UI: render dashboard

Each step is timed and recorded in agentTrace in the response. If a step fails, its section shows "Data unavailable", the rest still renders, and confidence drops.

Mock data

  • The app uses no mock data at runtime. If Yahoo fails, you see "N/A" or "Data unavailable", never invented numbers.
  • Synthetic price series exist only in backend/tests/conftest.py, so tests run without internet.
  • docs/demo/*.json are saved copies of real responses from 14 Oct 2026, kept as samples. The app does not read them.

Caveats on "real"

  • yfinance reads Yahoo's unofficial endpoints. Quotes can be delayed about 15 minutes, and Yahoo can rate-limit or change fields without notice.
  • The sector medians are approximate typed-in numbers, not live. Treat the "vs sector" charts as rough.
  • Finnhub news, Alpha Vantage news and FRED's 10Y yield are wired in but switched off until you add their keys. A Finnhub earnings-surprise function exists in enrichment.py but is not used yet.

5. When the LLM runs

WhereWhat it doesIf no key or it fails
News labelsOne call per analysis. Reads up to 18 headlines and returns sentiment, impact, reason and catalyst for each.Keyword lists in agent/news.py. The UI shows "classifier: lexicon".
NarrativeOne call per analysis. Gets the finished JSON and writes the summary, bull case, bear case and risks.A template built from the top drivers. The UI shows "Template summary".
NeverScores, rating, confidence, horizons, trade plan, any chart or table number.Not applicable.
  • Guard: after the LLM writes the narrative, code checks every number in it against the JSON. If more than 15% of figures are not in the data, the text is thrown away and the template is used.
  • Provider: set by LLM_PROVIDER in .env: nvidia (open Nemotron models), openai (any compatible server, such as Ollama) or anthropic (Claude). Code is in agent/llm.py.
  • Speed: the 120B Nemotron reasoning model took about 130 seconds for a full analysis. A smaller model through LLM_MODEL will be faster.
  • Compare view: it skips the narrative but still sends headlines to the LLM when a key is set. That is a leftover that should be fixed.

9. Run it on your phone for free

The repo now has a single Dockerfile that builds the UI and serves it with the API from one URL, and a render.yaml for Render's free plan.

Deploy on Render (free)

  • Push the project to a GitHub repository. .env is already git-ignored, so the key is not uploaded.
  • On render.com choose New, Blueprint, pick the repo. It reads render.yaml.
  • When asked, paste NVIDIA_API_KEY as an environment variable.
  • Open the https://….onrender.com address on your phone.

The free plan sleeps after about 15 minutes idle, so the first load takes 30 to 60 seconds. Memory is limited, which suits this app because the cache is in memory.

Quick look without deploying

With the app running on your computer and the phone on the same Wi-Fi, open http://<your-PC-IP>:5173. For a public link from your own PC, a Cloudflare quick tunnel (cloudflared tunnel --url http://localhost:5173) works while the PC is on.

Before you host

  • The NVIDIA key was pasted into a chat. Create a new one at build.nvidia.com and revoke the old one.
  • Anyone with the URL can use the API and spend your key's quota. Keep the link private or add a password later.
  • Yahoo sometimes blocks cloud server addresses. If hosted data comes back empty while it works locally, that is the cause.
